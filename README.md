# 下载结束自动关机

Windows 专用的小工具：当网络下载、磁盘写入和 CPU 占用同时进入低水平并持续一段时间后，
自动进入关机倒计时。默认持续 10 分钟、倒计时 120 秒，阈值和时长都可以在主界面点击
“设置”直接修改，速率单位可自行填写。主要针对 Steam 下载/安装，也适用于其他下载器，
不需要接入任何下载器 API。

> **当前版本已开启真实关机（`DRY_RUN = False`）。**
> 监控触发倒计时后，倒计时结束会真正执行系统关机。请先确认阈值，必要时点击“取消关机”，
> 或直接“停止监控”。

## 使用

### 直接运行 exe

源码仓库不提交打包后的 exe；请自行使用 PyInstaller 打包，或从 Releases 下载。
双击 `自动关机.exe` 即可使用。当前为**真实模式**：倒计时结束后会真正关机。
如果只是测试，请在倒计时期间点击“取消关机”，或先不要开始监控。

### 从源码运行

需要 Windows + Python 3.10 以上（安装 Python 时保留 tcl/tk）：

```powershell
py -m pip install -r requirements.txt
py auto_shutdown.py
```

### 界面与托盘

- 主窗口有四个按钮：`开始监控`、`停止监控`、`取消关机`、`设置`。
- 点击“设置”可直接在软件界面中修改阈值，保存后**立即生效**，同时写入 `config.ini`。
- 网络和磁盘阈值的单位可手动填写，默认 `KB/s`；也支持 `B/s`、`MB/s`、`GB/s`，填写 `KB`、`MB` 等也可识别。
- 未监控时点击“开始监控”，会开始判断并自动打开“实时监控”窗口。
- 监控中第一个按钮变为“查看监控”，点击可重新打开实时监控窗口。
- 关闭实时监控窗口只会隐藏它，不影响后台判断。
- 关闭主窗口会最小化到系统托盘，程序不会退出。
- 托盘菜单：显示主窗口、查看实时监控、开始监控、停止监控、取消关机、打开配置文件、退出。
- `取消关机`只在关机倒计时期间可用；取消后回到“未监控”状态，不会自动重新开始监控。
- 关机倒计时期间“设置”按钮不可用，避免分心或误改。

## 判断规则

以下三项**同时满足并持续配置的时长**才进入倒计时。下表是默认值：

| 项目 | 默认值 | 配置项 |
| --- | --- | --- |
| 网络下载速率 | 低于 100 KB/s | `net_low_value` + `net_low_unit` |
| 磁盘写入速率 | 低于 700 KB/s | `disk_low_value` + `disk_low_unit` |
| CPU 占用率 | 低于 10% | `cpu_low_percent` |
| 持续时间 | 10 分钟 | `low_activity_minutes` |
| 关机倒计时 | 120 秒，可取消 | `countdown_seconds` |

“实时监控”窗口显示当前网速、磁盘写入、CPU、三项是否均低于阈值、低活动持续时间，
以及距离触发/关机的时间。主窗口不显示这些实时数据，只保留一行简短状态。

## 修改阈值

推荐直接在主窗口点击“设置”：

- 网络下载阈值、磁盘写入阈值：填写数值并选择/输入单位，默认 `KB/s`。
- 单位可直接填写 `B/s`、`KB/s`、`MB/s`、`GB/s`；填写 `B`、`KB`、`MB`、`GB`、`K`、`M`、`G` 或中文单位也会识别。
- CPU 阈值单位固定为 `%`，低活动持续时间单位固定为分钟，关机倒计时单位固定为秒。
- 点击“保存并应用”后立即生效，并自动写入程序同目录的 `config.ini`。
- 如果正在监控，修改阈值会重置当前的低活动计时，避免新旧阈值混用。

`config.ini` 仍可手动编辑，默认内容如下：

```ini
[thresholds]
net_low_value = 100
net_low_unit = KB/s
disk_low_value = 700
disk_low_unit = KB/s
cpu_low_percent = 10
low_activity_minutes = 10
countdown_seconds = 120
```

- 手动编辑 `config.ini` 后需要**退出并重新启动程序**才会生效。
- 仓库中的 `config.example.ini` 只是示例；`config.ini` 属于本机配置，不纳入 Git。
- 也可以从托盘菜单选择“打开配置文件”。
- 只复制 exe 到新目录也可以；首次启动会在 exe 同目录自动生成默认 `config.ini`。
- 如果配置项缺失、格式错误或超出范围，启动时会弹窗提示，并使用该项的默认值，其他有效项仍会生效。

可在“实时监控”窗口中核对当前生效的阈值。

## 真实关机与模拟模式

源码顶部当前为：

```python
DRY_RUN = False  # 已启用真实关机
```

真实模式下，倒计时结束会执行：

```text
shutdown /s /t <countdown_seconds，默认 120>
```

点击“取消关机”会执行：

```text
shutdown /a
```

如果只想测试、不希望真正关机，把源码顶部改回：

```python
DRY_RUN = True
```

然后重新运行源码或重新打包 exe。模拟模式不会调用任何真实的 `shutdown` 命令。
当前交付的 exe 是在 `DRY_RUN = False` 下打包的。

## 打包 exe

```powershell
py -m pip install pyinstaller
py -m PyInstaller --noconfirm --clean --onefile --windowed `
  --name "自动关机" --icon "app.ico" `
  --hidden-import pystray._win32 auto_shutdown.py
```

生成位置：`dist\自动关机.exe`。`--windowed` 表示不显示控制台窗口。

> `DRY_RUN` 在打包时写进 exe；阈值在运行时读取，并可在主界面“设置”中直接修改。
> 修改阈值不需要重新打包；切换模拟/真实模式需要重新打包。

## 日志

- 位置：程序同目录下 `logs\app.log`。
- 记录：启动、配置加载/保存、开始/停止监控、进入/离开低活动、触发关机、取消关机、退出、异常。
- 自动轮转：单文件约 1 MB 轮转，保留 `app.log.1` 至 `app.log.3` 共 3 个备份，更旧的自动删除。

## 安全说明

- **当前版本为真实模式，倒计时结束会真正关机。**
- 默认生产参数为：网络低于 100 KB/s、磁盘低于 700 KB/s、CPU 低于 10%，
  持续 10 分钟；倒计时 120 秒。
- 真实模式下，退出程序时会尝试取消已经计划的系统关机；如果取消失败，会明确询问是否仍要退出。
- 如果在真实倒计时期间用任务管理器强制结束程序，Windows 中已经计划的关机仍然有效，请用 Windows 自带的“取消关机”或 `shutdown /a` 取消。
- 关闭主窗口只是隐藏到托盘。要退出请使用托盘菜单的“退出”。
- 如果暂时不需要自动关机，请点击“停止监控”，不要只关闭窗口。

## 限制

- 仅支持 Windows。
- 不接入下载器/Steam API，只依据整机网络、磁盘和 CPU 活动判断。
- 其他后台下载、系统更新、杀毒扫描等会影响判断：可能延后关机，也可能在系统确实低活动时按预期触发。
- 下载到内存盘、写入缓存在内存、或解压/安装几乎不产生磁盘写入的极端场景，可能被提前判断为结束。
